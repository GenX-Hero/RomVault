I file utilizzati da RomVault sono:

romvault.py	: Il programma in Python
romvault.cfg	: Un file config in formato JSON personalizzabile
romvault.lng	: Un file in formato JSON con i set di lingua.
romvault.map	: un file in formato JSON con il mapping tra i campi del db,
		  i tag dell'XML di ES-DE e le regole di trasformazione e di
		  normalizzazione dei dati.
romvault.db	: Il database in SQLite3 (se manca viene ricreato)
romvault.art	: File che contriene l'ASCII Art del titolo del programma.
romvault.sec	: File in formato JSON con credenziali per integrazione Google Cloud
romvault.rak	: File con username e API Key per RetroAchievement
